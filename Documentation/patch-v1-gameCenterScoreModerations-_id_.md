# Modify a Game Center Score Moderation

Block or unblock a score submitted to a leaderboard.

## Overview

Blocking a score removes it from the leaderboard, and unblocking reinstates it. The response contains the updated [`GameCenterScoreModeration`](/documentation/AppStoreConnectAPI/GameCenterScoreModeration) in a [`GameCenterScoreModerationResponse`](/documentation/AppStoreConnectAPI/GameCenterScoreModerationResponse).
